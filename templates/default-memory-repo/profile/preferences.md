# Preferences

This file stores stable engineering preferences that should usually be considered during AI coding work.

Keep entries concise and durable. Do not store temporary task context here.

## Engineering Preferences

- Prefer the existing codebase patterns over introducing new abstractions.
- Keep changes scoped to the requested behavior.
- Favor readable, maintainable code over clever code.
- Add tests when behavior changes or risk is non-trivial.

## Tooling Preferences

- Prefer local project commands and scripts over global assumptions.
- Prefer explicit verification before claiming work is complete.

## Communication Preferences

- Be direct and concrete.
- Surface risks, assumptions, and verification gaps.
