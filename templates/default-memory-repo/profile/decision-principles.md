# Decision Principles

This file stores durable principles for engineering decisions.

Use this for guidance that should apply across projects. Put project-specific decisions under `projects/`.

## Principles

- Preserve user data and user-owned changes.
- Prefer reversible changes when uncertainty is high.
- Keep source-of-truth data human-readable when practical.
- Treat privacy and secret handling as product requirements, not implementation details.
- Do not add infrastructure before the workflow proves useful.
