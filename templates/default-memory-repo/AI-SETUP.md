# AI Setup

This repository is a private Knowblazer engineering memory repo.

Use it as durable context for AI coding work. Do not treat every file as equally reliable. Prefer reviewed long-term memory over raw notes.

## How To Read This Repo

Start with:

- `profile/preferences.md`
- `profile/decision-principles.md`
- the relevant file under `projects/`
- the relevant files under `experience/`
- today's and yesterday's files under `daily/`, if they exist

Avoid by default:

- `inbox/`, unless the user explicitly asks you to inspect candidate notes
- `quarantine/`, unless the user explicitly asks you to help sanitize sensitive content
- `recall/`, unless the user asks to reuse a previous recall pack

## Safety Rules

- Do not reveal secrets, tokens, passwords, private keys, database URLs, customer data, or internal credentials.
- Do not commit or push content that looks sensitive.
- If a note contains sensitive content, move it to `quarantine/` or ask the user before continuing.
- Keep long-term memory concise and reviewable.

## Memory Layers

- `inbox/`: raw candidate memory waiting for review
- `daily/`: short-term working notes
- `profile/`: stable developer preferences and principles
- `projects/`: durable project context
- `experience/`: reusable engineering lessons
- `system/`: memory and privacy policies
- `quarantine/`: sensitive or risky content
- `recall/`: generated task context packs
